CVE:        N/A (misconfiguration)
CVSS:       7.8 (High)
Location:   SYSVOL share - garfield.htb\scripts\

Description:
  j.arbuckle has write access to L.WILSON's scriptPath attribute via an
  attribute-level ACE. Combined with write access to the SYSVOL share
  (garfield.htb/scripts), this allows uploading a malicious logon script
  that executes when L.WILSON authenticates.

Impact:
  - Code execution as l.wilson on DC01
  - Lateral movement from j.arbuckle to higher-privilege account
  - Pivoting point for further AD exploitation

4.4 Resource-Based Constrained Delegation (RBCD) on RODC01 (EXPLOITED)

CVE:        N/A (misconfiguration)
CVSS:        (Critical)
Location:   RODC01$ computer object - msDS-AllowedToActOnBehalfOfOtherIdentity

Description:
  l.wilson_adm (Tier 1) has the ability to create computer accounts in
  the domain (msDS-MachineAccountQuota). A fake computer account HACKER$
  was created, and RBCD was configured to allow HACKER$ to impersonate
  any user to RODC01. This was used with S4U2Self/S4U2Proxy to obtain
  a Kerberos ticket as Administrator for RODC01's CIFS service, leading
  to SYSTEM access via psexec.

Impact:
  - Complete SYSTEM-level compromise of RODC01
  - Foundation for krbtgt_8245 extraction and Golden Ticket attack
  - Full domain compromise pathway established

Remediation:
  - Restrict who can create computer accounts (remove from Tier 1)
  - Audit msDS-AllowedToActOnBehalfOfOtherIdentity on all computer objects
  - Monitor for newly created computer accounts
  - Restrict msDS-MachineAccountQuota to 0 if not needed

Commands used:

  proxychains rbcd.py -delegate-from 'HACKER$' -delegate-to 'RODC01$' \\
    -action write 'garfield.htb/l.wilson_adm:NewPass123!' \\
    -dc-ip 10.129.244.207

  # Sync time (avoid Kerberos skew)
  sudo ntpdate 10.129.244.207

  # Request S4U ticket as Administrator
